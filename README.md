# YOKA TECH PRO — Complete Android Project

A polished Flutter Android shop-management app for YOKA TECH.

### Included
- Premium dark Material 3 UI
- Dashboard with sales/profit/stock snapshot
- Phone + accessories stock
- IMEI/SKU fields and low-stock alerts
- POS billing with automatic stock deduction
- Local persistence (SharedPreferences)
- Repair jobs with advance/balance/status
- Customers
- Sales reports
- PDF invoice sharing/printing
- WhatsApp share flow
- Barcode/QR camera scanner
- Owner/Cashier/Technician-ready navigation
- Android project folder included

### Build on Windows
1. Install Flutter SDK and Android Studio.
2. Open this project folder in Android Studio.
3. Terminal:
   flutter doctor
   flutter pub get
   flutter build apk --release
4. APK:
   build/app/outputs/flutter-apk/app-release.apk

### Important
Cloud sync/Firebase, WhatsApp Business API automatic messaging, and production authentication require your own service credentials/configuration. The app currently provides local persistence plus share/scanner/invoice integrations without hard-coded private credentials.
